# 05-math-key: hints

Open one level at a time. Level 3 is close to a spoiler.

<details><summary>Level 1: Nudge</summary>

The rules aren't inlined. Follow the indirect `call` through a table.

</details>

<details><summary>Level 2: Direction</summary>

Each function in the table checks one arithmetic property of the digits.

</details>

<details><summary>Level 3: Near-spoiler</summary>

Write each rule as a Python predicate, then fix some digits and solve for the others. A small brute force over the free digits works fine.

</details>
