# 22-antidebug-mix: hints

Open one level at a time. Level 3 is close to a spoiler.

<details><summary>Level 1: Nudge</summary>

No checks branch to 'debugger detected'. They change the key instead.

</details>

<details><summary>Level 2: Direction</summary>

Four salts (ptrace, TracerPid, timing, code checksum) all go into the derivation.

</details>

<details><summary>Level 3: Near-spoiler</summary>

Work out each salt's clean-run value statically, plug them in, and derive the key without running under a debugger.

</details>
