# 24-aarch64: hints

Open one level at a time. Level 3 is close to a spoiler.

<details><summary>Level 1: Nudge</summary>

AArch64 name/serial. Learn `ldrb`, `eor`, `ror`, `madd`.

</details>

<details><summary>Level 2: Direction</summary>

The name hash loop is the core. The serial compare is at the end.

</details>

<details><summary>Level 3: Near-spoiler</summary>

Port the hash to Python and print a serial for any name. Check it with qemu-aarch64 if you have it.

</details>
